Agent 三種設計模式

AI 代理

Reflection 讓模型自己改答案，Tool Use 讓模型去查或做，Planning 讓模型先拆步驟再執行。

三種模式比較

模式核心流程適合情境
Reflection產生 → 自我評論 → 修改寫作、程式碼品質
Tool Use判斷要呼叫的工具 → 執行 → 把結果交回模型查資料、計算、操作檔案
Planning拆解任務 → 逐步執行 → 視結果調整多步驟專案任務

怎麼選

模型缺的是「資訊或能力」就用 Tool Use；缺的是「品質」就用 Reflection；缺的是「順序與全局」就用 Planning。三者也能組合，例如先 Planning，每一步再 Reflection。

自我檢查

Reflection 一定要多一次模型呼叫嗎？是，至少多一次用來評論或修改。
Tool Use 裡，工具結果要怎麼處理？回傳給模型，讓它依結果產生最終回答。
什麼任務適合 Planning？步驟多、前後有依賴的任務。
